# cascade_start_reverse_stop

When all circuit breakers are closed you can use the START button to initialize a 5 seconds countdown before the first pump (BB1), then initializing another 5 seconds for the second pump (BB2).

After pressing the STOP button it starts the shutdown process, repeating previous one in the other way, 5 seconds delay, turn off BB2, another 5 seconds turn off BB1.

While it happens there's also a pair of LEDs, one for each pump, that keep turning on and off when the pump is about to get turned on or off.
